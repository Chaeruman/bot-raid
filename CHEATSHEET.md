# 📋 Loot Panel — Cheat Sheet

**Alur:** Set Seller → Type Items → kasih harga → Mark Paid → panel nutup sendiri.

## ✍️ Type Items (1 baris = 1 item)
```
gdn (chakram)            item bernama (keyword)
gdn squad ring atk       accessory: unique/legend + ring/neck/ear + sub
thorns l junk            rune: jenis + l/u + junk/good
gdn armor warrior head   equipment biasa
gdn fragment x5          fragment + jumlah
gold 294/7 @ol           gold ÷7 (tag yg TIDAK dapat) · 258/8 = ÷8
```
- Tambahan: `x5` jumlah · `#catatan` · pisah banyak item dgn `|`
- Ragu/lupa junk-good? Bot tanya bernomor → pencet **Resolve** → ketik `1, 2`

## 🏷️ Harga
- **Price All**: isi setelah `=` → `1. GDN Chakram = 50000`
- Boleh hitung: `100000/8`, `50000*2`, `(50000+10000)*2`

## 💰 Gold
- `gold 294/7 @nama` (HC, 1 orang dikecualikan) atau `258/8` (normal)

## Sisanya
- **Seller** = item & harga · **Host** = member & close · Mark Paid = dua-duanya
- **Mark Paid** semua → auto-close · **Add/Remove Member** bisa pilih banyak
